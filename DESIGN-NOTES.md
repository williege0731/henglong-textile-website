# Etro Textiles → Henglong design translation

Studied https://etrotextiles.etro.com/ (public pages + Awwwards palette notes).
No Etro logos, product photography, IvyMode font files, or proprietary code were copied.

## Observed cues (Etro Textiles)
- Chrome: Menu (hamburger + label) left · centered wordmark · sparse utility links right
- Palette: near-black #1A1A1A on warm off-white #F4F2EF (Awwwards)
- Type: Inter for UI; display serif (IvyMode on source) for names/titles
- Home: full-bleed hero, small uppercase kicker, large stacked serif title, outlined CTA, SCROLL cue
- Catalog: sticky pill filters; 4-column square swatch grid; serif all-caps name + tiny uppercase type label + color dots; floating Pattern/Type/Use chips + Line/Grid toggle
- Motion: soft image scale on hover; drawer slide-in menu

## Henglong translation
- Same IA feel: drawer Menu, centered「恒隆纺织」, 图鉴/联系 utilities
- Same palette tokens and Cormorant Garamond + Inter (licensed Google Fonts stand-ins—not IvyMode)
- Home lookbook hero + featured 3-col editorial tiles + catalog teaser grid
- Products =「explore fabrics」with Chinese category pills and HL · 01–12 photographic cards
- About/Contact stay image-led, quiet chrome; Chinese copy for yarn-dyed factory; no fake phones/certs
- Imagery: existing Wikimedia/Pexels-optimized files in images/web/ only
