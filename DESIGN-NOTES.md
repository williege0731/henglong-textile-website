# Effect fidelity notes (Henglong vs Etro Textiles)

Reference observed: https://etrotextiles.etro.com/ (public pages only).
Henglong uses original CSS/JS + licensed fabric photos in `images/web/`. No Etro assets, logos, IvyMode fonts, or proprietary code.

| Etro effect | Henglong polish |
|---|---|
| Wheel-driven pinned full-screen stage | Sticky 560vh stage scrubbed by native scroll (smoothed/lerped) |
| Hero wipe → giant DISCOVER headline | Hero clip-path wipe + dual Chinese/EN frames → 「探索 / 新面料」 |
| Tilted polaroid cards crossing type | 8 licensed-fabric cards, tilt + bob + hover straighten/zoom |
| Transparent → solid header; hide on scroll | Same; stays visible in early hero phases |
| Drawer with staggered links | Slide-in drawer, staggered Bodoni links |
| Horizontal collection rails | Drag + inertia + progress bar + hover zoom |
| Fabrics: pills, Pattern/Type/Use dock, Line/Grid | Sticky pills, bottom dock show/hide, Line list layout, swatch hover swap |
| Product photography / IvyMode | Henglong licensed JPEGs + Bodoni Moda (Google Fonts) |

Still different: no hero video; no paid IvyMode; scroll not wheel-hijacked; no Etro wishlist/distributors.
